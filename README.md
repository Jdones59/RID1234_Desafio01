# Arquitetura Moderna — Landing Page

Uma landing page simples e moderna para apresentação de serviços de arquitetura, com hero em carrossel, sessão de projetos, modal de contato e envio de formulários via SheetMonkey.

## 🚀 Tecnologias

* HTML5
* CSS3 (grid, responsivo, variáveis)
* JavaScript (carrossel, modal, formulário)

## 📂 Estrutura

* `index.html` — Estrutura principal da página
* `assets/css/style.css` — Estilos globais
* `assets/js/script.js` — Lógica do carrossel, modal e envio
* `assets/img/` — Imagens do site

## ✨ Funcionalidades

* Carrossel automático no Hero
* Formulário conectado ao SheetMonkey
* Modal com envio + redirecionamento WhatsApp
* Menu responsivo mobile

## 🔧 Como usar

1. Baixe o projeto
2. Substitua o link do formulário no `action="..."`
3. Abra o `index.html` no navegador ou hospede em qualquer servidor estático

## 🌎 Deploy recomendado

* GitHub Pages
* Netlify
* Vercel
